CRUD-проект "Сервис управления складским учетом книг".

Это RESTful-приложение, разработанное на Java с использованием экосистемы Spring Boot. Оно предоставляет HTTP-интерфейс для выполнения операций CRUD (Create, Read, Update, Delete) над сущностью «Книга» в контексте складского учёта. Проект предназначен для демонстрации базовых навыков разработки бэкенд-приложений с типовой трёхуровневой архитектурой: контроллер → сервис → репозиторий.
Основная задача приложения — вести учёт книг на складе: добавлять новые позиции, просматривать список всех книг и отдельные записи, редактировать информацию о книгах, удалять записи, а также получать агрегированную статистику по количеству наименований и общему числу экземпляров.


Инструкция по запуску приложения на Вашей машине.

На машине уже должен быть установлен и ЗАПУЩЕН Docker!!!!


Шаг 1. Скачайте проект к себе на машниу.

Шаг 2. Откройте командную строку и перейдите в путь с содержимым скачанного проекта.

Шаг 3. Запустите все необходимые сервисы, которые указаны в файле docker-compose.yml
Для этого в командной строке выполните команду: docker-compose up -d --build

Готово. Приложение запущено. Для тестирования приложения используйте Postman (или т.п.) (http://localhost:8080/api/books) + OpenAPI (http://localhost:8080/swagger-ui.html).
