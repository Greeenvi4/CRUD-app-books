Инструкция по запуску приложения на Вашей машине.

На машине уже должен быть установлен и ЗАПУЩЕН Docker!!!!


Шаг 1. Скачайте проект к себе на ПК.

Шаг 2. Откройте командную строку и перейдите в путь с содержимым скачанного проекта.

Шаг 3. Запустите все необходимые сервисы, которые указаны в файле docker-compose.yml. 
Для этого в командной строке выполните команду: docker-compose up --build.

Готово. Приложение запущено. Для тестирования приложения используйте Postman + OpenAPI.
